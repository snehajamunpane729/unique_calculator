# unique_calculator
A simple Python-based calculator that performs basic and advanced mathematical operations through a menu-driven interface.

UNIQUE CALCULATOR
Introduction
Unique Calculator is a simple calculator program made using Python. I created this project to perform different mathematical calculations from one program instead of writing separate programs for every calculation.
The program shows a menu of operations, and the user can enter the number of the operation they want to perform. After taking the required input, the program calculates and displays the result.
Apart from basic calculations, the calculator also includes operations such as percentage, roots, average, GCD, LCM, prime number checking and factorial.
Features
The calculator currently provides the following options:
1.	Addition 
2.	Subtraction 
3.	Multiplication 
4.	Division 
5.	Power 
6.	Percentage 
7.	Cube Root 
8.	Square Root 
9.	Average 
10.	Greatest Common Divisor (GCD) 
11.	Least Common Multiple (LCM) 
12.	Prime Number Checking 
13.	Factorial 
14.	Exit

How to Run
The program requires Python to be installed on the computer.
To run the project:
1.	Open the project folder in Visual Studio Code. 
2.	Open the unique_calculator.py file. 
3.	Run the Python file using the Run button or the terminal. 
4.	The calculator menu will appear in the terminal. 
5.	Enter the number corresponding to the required operation. 
The program can also be run from the terminal using:
python unique_calculator.py
How to Use
When the program starts, it displays all the available operations.
The user has to enter the number of the operation they want to use. The program then asks for the required values.
For example, if the user enters 1, the program asks for two numbers and performs addition.
If the user selects 14, the program displays a thank-you message and exits.
