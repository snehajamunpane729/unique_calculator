Statement Description

Problem Statement:
Performing different mathematical calculations separately can be inconvenient. This project solves this by providing multiple calculations in one simple program.

Scope of the Project:
The project covers basic arithmetic as well as percentage, square root, cube root, average, GCD, LCM, prime checking, and factorial calculations. It currently works as a command-line Python application.

Targeted Users:
The calculator is mainly useful for students, beginners learning Python, and users who need quick basic mathematical calculations.

High-Level Features:

Menu-driven interface
14 calculation options
Arithmetic and mathematical operations
GCD and LCM calculation
Prime number and factorial checking
Continuous operation until the user chooses Exit
Simple command-line interaction
